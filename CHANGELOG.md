# Changelog

All notable public documentation changes to the Diamond Brew method will be recorded here.

## Unreleased — 2026 repository rebuild

### Added

- evidence classification framework;
- current development status;
- scientific working hypothesis with testable predictions;
- evidence and limitations register;
- pressure, food-contact, and shelf-stability safety boundaries;
- experiment program and reusable experiment template;
- explicit boundary between public research documentation and private commercial specifications.

### Changed

- reframed the process as elevated-temperature extraction in a closed pressurized vessel;
- replaced fixed recipe language with a current developmental method envelope;
- separated freeze-assisted clarification from freeze concentration;
- distinguished practical observations from validated scientific and food-safety claims;
- updated filtration, agitation, dilution, resting, and measurement descriptions.

### Deferred

- licensing changes;
- primary-literature bibliography;
- exact commercial production specification;
- validated shelf-life claims.
