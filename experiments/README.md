# Experiment Program

The experiment directory is intended to convert accumulated practical learning into traceable evidence.

## Experimental priorities

1. Separate temperature effects from pressure effects.
2. Measure the influence of hold time.
3. Quantify agitation effects.
4. Compare coffee-to-water ratios using a single coffee.
5. Compare water profiles blind.
6. measure clarification recovery and sensory change.
7. construct dilution-preference curves.
8. characterize refrigerated resting over time.

## Minimum design principles

- Change one primary variable at a time when possible.
- Record coffee, roast date, grinder, grind setting, batch size, vessel, and water.
- Define the outcome before tasting.
- Randomize sample codes for sensory comparisons.
- Include repeats and a reference condition.
- Record negative and null results.
- Separate instrumental results from sensory interpretation.
- Do not infer microbial safety from taste, smell, appearance, or process temperature alone.

Use [EXPERIMENT-TEMPLATE.md](EXPERIMENT-TEMPLATE.md) for new work.

## Suggested naming

Use a stable identifier such as:

`DB-YYYYMMDD-COFFEE-SEQ`

Example:

`DB-20260918-TARRAZU-01`

Samples derived from a batch can append conditions:

`DB-20260918-TARRAZU-01-DIL1x5`
