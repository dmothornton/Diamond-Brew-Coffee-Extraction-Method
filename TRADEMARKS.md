# Method Name and Branding

## Diamond Brew as a method name

“Diamond Brew” is used in this repository as the descriptive name of a coffee brewing methodology defined by direct extraction of ground coffee in water at nominally 121 °C.

Anyone may accurately:

- refer to the Diamond Brew method;
- state that an experiment uses, evaluates, replicates, or modifies the method;
- compare another brewing method with Diamond Brew;
- identify a beverage as produced using the Diamond Brew method when the defining condition is met.

Users should disclose material deviations from the documented method and should not describe a lower-temperature process as Diamond Brew without making the difference explicit.

This permission to use the method name descriptively does not constitute certification and does not imply that every use of the name is scientifically accurate, safe, endorsed, or commercially associated with the method's developer.
